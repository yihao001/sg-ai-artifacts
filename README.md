# sg-ai-artifacts

> A starting point for open-source AI/ML projects related to use-cases in Singapore.

What does this repo offer? 
1. Data Sources (w/ notes about undocumented quirks)
2. Processed Data (w/ pre-processing scripts)
3. Model checkpoints (w/ model training scripts)
4. Project demo/examples
5. Unexplored problems / project ideas that are waiting for your contributions! 😄

Basically, what's different is we've actually used the resources before so we can tell you more about the usage experience, what to avoid, etc. so that you don't make the same mistakes.

# Sitemap
- `README.md` - landing page
- `overview.md` - cross-application resources
- `/<application>` and `<application>.md` - Application-specific resources


# Contribute
- PRs are very welcome and strongly encouraged! Share your work so that others can build on top of it and not repeat what you did. Especially if you have worked on one of the unexplored problems mentioned here!
- As vibe coding makes it significantly easier to spin up a project these days, we probably need some QC and careful curation at some point. For now, the core set of curated information is kept in the main markdown files (overview and application-specific ones) and we could have a `compiled.md` file which will collate public submissions.


# Motivation

- There have been several past efforts to perform such collation but they don't seem to be active now. Enough people have PM-ed me about my past projects so while I'm around, this will always be updated.
- While coding agents make it really quick to produce scripts and dashboards, many other aspects of AI such as model training still require plenty of resources that are not always available so there's still much value in sharing them (e.g. checkpoints). Also, we try our best to make cleaned datasets meant for multiple use, not just project-specific needs.
- Quite a lot of projects I've seen have significant overlaps, so increasing the discoverability of what people have already done could avoid duplication of efforts and make it clearer what problems are left unsolved. Perhaps the next generation of students will consider working on these problems in their projects (and build on top of existing work!). 😄
